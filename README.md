## Overview
This project provides a clean, responsive currency converter widget designed specifically for Chinese-speaking users. It features a user-friendly interface for swapping currencies and performing real-time conversions using built-in demo rates, making it perfect for quick offline checks or simple web integration without the need for complex API keys.

## Features
*   **Swap Functionality:** Instantly toggle between base and target currencies.
*   **Popular Currencies:** Pre-configured with major global currencies including CNY, USD, EUR, JPY, and more.
*   **Zero API Dependency:** Uses hardcoded demo exchange rates to ensure 100% uptime and privacy.
*   **Responsive Design:** Optimized for both mobile and desktop screens using modern CSS.
*   **Lightweight:** Single-file architecture for lightning-fast loading.

## Localization Notes
*   **Language:** Fully localized for Simplified Chinese (zh-CN) users.
*   **Formatting:** Follows standard Chinese numeric formatting and currency display conventions.
